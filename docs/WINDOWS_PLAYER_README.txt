雨蚀：第九病区 / RAINROT · WARD 09
Windows 桌面版

开始游戏
将 ZIP 完整解压到一个文件夹，双击 RAINROT.exe。
请让 RAINROT.exe 和 RAINROT.pck 始终位于同一个文件夹。
不需要安装 Godot、Python，也不需要联网。

运行环境
Windows 10/11 64 位，支持 Vulkan 的显卡及较新显卡驱动。
本版采用 Forward+ 渲染，保留体积雾、环境遮蔽、间接光和反射。
如运行不流畅，可在“视听设置”中降低画质。

操作
WASD 移动，鼠标观察，Shift 冲刺，Ctrl 蹲伏。
E 交互，F 手电，左键射击，右键瞄准，R 换弹。
Tab 背包，J 日志和地图，Esc 暂停，F11 全屏。
建议佩戴耳机。

存档与更新
安全区录音机和章节节点保存进度。
存档位于 Windows 用户数据目录：
%APPDATA%\Godot\app_userdata\雨蚀：第九病区 - RAINROT\
更新时把新版解压到新文件夹即可，存档不在游戏解压目录里。
未来版本的存档兼容性请查看对应版本说明。
