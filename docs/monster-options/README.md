## 1. 笑面病患

![Smily horror monster 原作预览](https://media.sketchfab.com/models/3d3fc31eddaa409a8f2df564823154e1/thumbnails/654c7cdc4e494fc9a0f455c4fbaa7fec/c45efcabb17a461a87cf6492aeda39ad.jpeg)

原作：[Smily horror monster](https://sketchfab.com/3d-models/smily-horror-monster-3d3fc31eddaa409a8f2df564823154e1)，作者 **Bento**。

外观：空洞眼窝、固定露齿的笑脸，头部前倾，手臂低垂。远处仍像一个人，靠近后表情完全没有回应。

拟议改造：加上破损病号服、编号腕带和皮肤潮湿感；保留面部明暗反差，减少鲜红色面积。

拟议遭遇：先让它站在走廊尽头侧身不动；听到脚步后慢慢转头，再以不规律步伐靠近，接近时突然加速。

接入条件：页面记录 1 段动画；尚不能确认包含行走、攻击、受击和死亡动作。需检查骨骼，并补齐动作集。 页面面数 23,820。工作量：中等。

建议：五个里最适合成为第九病区的标志性主敌人。

## 2. 多肢护士

![Horror Mutant Bloody Nurse Gore (RIGGED) 原作预览](https://media.sketchfab.com/models/2bc6e1cac98e458a824691009ef2433c/thumbnails/9b3138031b3045efb4ea5a7a1ed55bb4/2ddb234880e542808249cb9b65f1cd71.jpeg)

原作：[Horror Mutant Bloody Nurse Gore (RIGGED)](https://sketchfab.com/3d-models/horror-mutant-bloody-nurse-gore-rigged-2bc6e1cac98e458a824691009ef2433c)，作者 **KrimzonHaze**。

外观：黑发遮面、残破的医疗服，身体向下分出尖锐的多肢轮廓。人体的熟悉感被肢体结构破坏。

拟议改造：改成疗养院旧式护理制服，头部增加遮光面罩和患者标签；降低鲜血饱和度，强调皮肤和布料质感。

拟议遭遇：关灯后先响起尖肢触地声；它从药柜侧面缓慢探出，攻击前用肢体撑高身体。

接入条件：作者明确标注完整骨骼绑定；页面动画数为 0，需要专门制作多肢行走和攻击。 页面面数 27,040。工作量：较高。

建议：医疗场景关联最强，肢体变形也最明显。

## 3. 长臂爬行者

![Creature [Rigged] 原作预览](https://media.sketchfab.com/models/06d2b90a1e24471283f6aaac748db1c9/thumbnails/127bf494531c45e6b02ef1f19e3e945f/c744d9ebfa6c464ea1ba63d069c05e89.jpeg)

原作：[Creature [Rigged]](https://sketchfab.com/3d-models/creature-rigged-06d2b90a1e24471283f6aaac748db1c9)，作者 **Fridge**。

外观：身体紧贴地面，前臂和手指异常修长，口部突出。它的攻击方向会落在玩家习惯观察的高度以下。

拟议改造：把黄绿色皮肤改为失血般灰白，加入实验编号、输液固定痕迹和局部湿润材质。

拟议遭遇：床下先出现手指和摩擦声；玩家走过后，它从身侧快速拖行出来。伏击前保留可辨识的声音提示。

接入条件：作者标注已绑定骨骼，含 2K 基础色、粗糙度和法线贴图；页面动画数为 0，需制作爬行与扑击。 页面面数 24,008。工作量：较高。

建议：适合与笑面病患搭配，让玩家同时担心前方和脚边。

许可：[CC BY 4.0](http://creativecommons.org/licenses/by/4.0/)。公开元数据：https://api.sketchfab.com/v3/models/06d2b90a1e24471283f6aaac748db1c9

## 4. 畸变实验犬

![Grimhound Rig 原作预览](https://media.sketchfab.com/models/417f6ff2d90043a7ab061d560801be93/thumbnails/e4453f1581094f7d9d0612029856e702/73528d33be9e4fab9e8e0996d8fcb6e1.jpeg)

原作：[Grimhound Rig](https://sketchfab.com/3d-models/grimhound-rig-417f6ff2d90043a7ab061d560801be93)，作者 **DM-913**。

外观：犬形头颅与巨大的牙床，背部隆起，四肢比例失衡。还保留动物轮廓，但行动姿态明显异常。

拟议改造：加入断裂项圈、植入标签和实验拘束带；调整肌肉与皮肤的光泽，统一为地下实验室的冷色调。

拟议遭遇：先在隔离门后喘息撞门；逃生时从侧方切入追击。用急促爪声提示加速，保留侧向闪避空间。

接入条件：资产标题标注 Rig，页面记录 1 段动画；完整跑动、扑咬和转向动作需要下载后核对。 页面面数 22,136。工作量：中等至较高。

建议：最接近生化实验失败产物的方向，适合强调追逐压力。

## 5. 巨口蛛体

![Spiderthing take 3 原作预览](https://media.sketchfab.com/models/10bb4cf49d304d64afd2b829666f6caf/thumbnails/9936bc2de37d48ff9751b71289f5e354/9c078e35378c4cc0b707d43b298b3b60.jpeg)

原作：[Spiderthing take 3](https://sketchfab.com/3d-models/spiderthing-take-3-10bb4cf49d304d64afd2b829666f6caf)，作者 **Rasmus**。

外观：巨大的口器、膨胀腹部和细长蛛足，脸部与虫体混合。腿部在墙上的投影会先于本体出现。

拟议改造：减弱甲壳的奇幻感，改成潮湿的灰白组织；加上实验固定夹与编号，缩放到现有地下路线可容纳的体型。

拟议遭遇：先从管线间投下长腿影子，再缓慢横穿出口；玩家启动设备后，它才开始追击。

接入条件：页面记录 2 段动画、约 6.8 万面；需要核对动作内容，处理蛛足运动、转弯宽度与碰撞。 页面面数 67,972。工作量：高。

建议：适合接受更强虫形怪物风格的选择，场景适配工作最多。

许可：[CC BY 4.0](http://creativecommons.org/licenses/by/4.0/)。公开元数据：https://api.sketchfab.com/v3/models/10bb4cf49d304d64afd2b829666f6caf

## 接入前核对

选定后获取原作者模型，检查骨骼层级、贴图和动画；优先整理为 glTF/GLB 导入 Godot。现有 enemy.gd 使用命名节点驱动程序动画，替换为骨骼角色时需要适配 AnimationPlayer/AnimationTree，不能只替换模型文件。

爬行和多肢模型需要额外检查低位攻击、转弯半径、楼梯、门框与安全区规则；完成后再用现有关卡验证性能和可通行性。

此目录仅为方案研究，未把这些模型加入正式资产许可清单。
